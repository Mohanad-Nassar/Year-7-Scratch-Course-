# Year 7 Computing – Student Dashboard (all units)

One self-contained page with all six Year 7 Computer Science units built in:

1. Digital Citizen Quest – Online Safety
2. Think Like a Computer – Computational Thinking
3. Binary Quest – Binary & Logic Gates
4. Inside the Machine – Elements of a Computer
5. Spreadsheet Wizards – Spreadsheets
6. Fruit Catch Quest – Scratch Programming

Pupils enter their name and house group, open any unit from the dashboard, and save or load their progress as a file. The dashboard tracks XP, badges and ranks across all units and gives a whole-year certificate.

Unit 6 loads its videos and screenshots from this repo's `media/` folder (via jsDelivr), so that unit needs an internet connection.
